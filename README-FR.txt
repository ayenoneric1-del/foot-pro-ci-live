FOOT PRO CI LIVE — GUIDE

Cette version contient l'interface mobile et les fichiers de base d'une PWA installable. Les matchs réels, scores en direct et liens de diffusion ne sont PAS encore connectés. Aucun score ou lien vidéo n'est inventé.

Pour afficher des données réelles, il faudra choisir une API de football et la configurer côté serveur afin de protéger la clé API. Les vidéos doivent provenir de diffuseurs autorisés en Côte d'Ivoire.

Publication possible : ouvre https://app.netlify.com/drop et dépose le dossier du site décompressé. Le dossier doit contenir index.html, style.css, app.js, manifest.json, service-worker.js et icons. Ouvre ensuite le lien HTTPS obtenu dans Chrome sur Android et utilise ⋮ > Installer l'application / Ajouter à l'écran d'accueil.

Ne supprime pas ton ancien projet Replit. Les hébergeurs gratuits peuvent avoir des limites.
